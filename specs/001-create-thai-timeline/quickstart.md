# Quickstart: สร้างอินโฟกราฟิก Timeline จาก PDF

## ความต้องการเบื้องต้น

- Python 3.11+ พร้อม `PyMuPDF`, `pytesseract` (ติดตั้งแล้วบนเครื่องนี้)
- Tesseract OCR พร้อมข้อมูลภาษาไทย (`script/Thai`) — ตรวจด้วย
  `tesseract --list-langs | grep -i thai`
- เว็บเบราว์เซอร์สมัยใหม่สำหรับเปิดผลลัพธ์

## สร้างอินโฟกราฟิกจากไฟล์ตัวอย่าง

```bash
python3 src/thai_timeline.py HW03-Input.pdf --output dist/hw03.html --report dist/report.json --force
```

ผลลัพธ์: `dist/hw03.html` — เปิดด้วยเบราว์เซอร์ จะเห็น timeline
แนวนอนบน canvas ขนาด 1200×675 พร้อมหัวเรื่องปฏิทินงบประมาณ พ.ศ. ๒๕๗๐
และเหตุการณ์สำคัญ 16 รายการที่เลือกจากข้อมูล 21 ลำดับ ครบทั้ง 3 กลุ่มกิจกรรม
ภาพตัวอย่างที่เรนเดอร์ไว้คือ `dist/hw03-preview.png`
HTML ฝังฟอนต์ Sarabun Regular/Bold ไว้ในไฟล์เดียวและแสดงตัวเลขอารบิกบนภาพ

ข้อมูล 21 ลำดับในไฟล์ตัวอย่างผ่านการตรวจทานกับภาพสแกนทั้ง 3 หน้า และจะถูกใช้
เฉพาะเมื่อ SHA-256 ของ PDF ตรงกับไฟล์ที่ตรวจทานไว้ใน
`src/timeline/hw03_verified.json` หากใช้ PDF อื่น โปรแกรมจะลองสกัดด้วย OCR
เพื่อทำรายงาน แล้วหยุดให้ตรวจทานก่อนสร้าง HTML

## ตรวจสอบคุณภาพ

```bash
# ตรวจ confidence ของ OCR และรายการที่ต้องตรวจทาน
cat dist/report.json

# รันชุดทดสอบ
python3 -m pytest tests/ -q
```

## กรณีพบปัญหา

- **exit 2**: ตรวจว่า path ของ PDF ถูกต้องและไฟล์ไม่เสีย
- **exit 3**: OCR ไม่มั่นใจ — เปิด report ดู `uncertain_terms` แล้วตรวจทาน
  กับต้นฉบับ หรือสแกนเอกสารใหม่ให้คมชัดขึ้น
- **exit 4**: เพิ่ม `--force` หากตั้งใจเขียนทับผลลัพธ์เดิม
